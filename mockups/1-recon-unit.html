Define how to subdivide the reconciliation timeframe

What is a Reconciliation Unit?
A reconciliation unit defines how your data will be subdivided for processing. For example, with a daily interval, the system will process one day of data at a time using the dateTimeRange you provide at runtime.
This determines how the system subdivides the dateTimeRange you provide at runtime.
Only UTC timezone is supported. All timestamps must be in UTC for consistency.

Preview

Configuration:

Data will be processed in daily intervals using UTC timezone.

Example Runtime Execution:

reconciliation-cli run --config job.yaml \
  --datetime-range 2024-03-15T00:00:00Z/2024-03-16T00:00:00Z

This will process one full day (2024-03-15) of data.

YAML Preview

Generated configuration

reconciliation_unit:
  interval: day  # day, hour, or minute
  timezone: UTC  # Only UTC supported

💡 Tips

  • Use day for standard daily reconciliation
  • Use hour for intraday processing
  • Use minute for near real-time reconciliation
  • All timestamps must be in UTC format
